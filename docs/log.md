## 2026-11-11
* **Update**: `e2sar_daos_recv --rd-fac N` (0–2) and `--rd-lvl rank|node` store N + 1 copies of a run worth keeping ([Redundancy](concepts/daos-layout.md#redundancy)). The first receiver creates the container with `rd_fac` N and `rd_lvl`; the default classes become `RP_<N+1>GX` and `RP_<N+1>G8`.
