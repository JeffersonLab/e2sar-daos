## 2026-11-05
* **Update**: [e2sar_daos_read](reference/e2sar_daos_read.md#a-full-disk---min-free) survives a full disk ([#38](https://github.com/JeffersonLab/e2sar-daos/issues/38)): new `--min-free` (GiB, default 5) pauses `--live` and `--live-rm` before a file that would leave less free in `-o DIR`, and resumes once there is room. Manifest lines are written whole or not at all, and a cut-off last line is dropped on restart, so a crash no longer blocks or misdirects the restart. Tested against LB 677 run 1. [e2sar_daos_monitor](reference/e2sar_daos_monitor.md) writes its JSON lines the same way and skips lines while the disk is full. `scripts/e2sar_live_pipeline.sh` starts the reader with `--min-free 50` (`READ_ARGS`) and `status` shows a paused reader ([scripts](reference/scripts.md), [live-monitoring](howto/live-monitoring.md#waiting-for-a-sender)). New unit suite `TextFilesTests`.
* **Creation**: `scripts/e2sar_live_pipeline.sh` ([scripts](reference/scripts.md)): `start`, `stop`, `status`, `recycle` and `watch` for the live pipeline from the laptop. `recycle` replaces a run that got no events for an hour (no sender) with a new one, never touching a run with data. Documented in [live-monitoring](howto/live-monitoring.md#waiting-for-a-sender) and [streaming-workflow](concepts/streaming-workflow.md#the-workflow). `e2sar_nicmon.sh report` lists `rx_steer_missed_packets` per second only above 100 (it is mostly background multicast).
* **Update**: Tagged the data type of the NERSC runs: [2026-11-04-nersc-lb675-evio](results/2026-11-04-nersc-lb675-evio.md) `cosmics`; [LB 677 run 1](results/2026-11-05-194730UTC-lb677-run1-evio.md) and [run 2](results/2026-11-05-201815UTC-lb677-run2-evio.md) `physics`.
* **Creation**: [hit-compression](concepts/hit-compression.md) (draft, prototyping ideas): how far LB 677 run 1 frames (97% hit words) compress: lz4 1.00x, zstd 1.17-1.30x, Parquet 1.22-1.65x, a hit-aware encoding 2.32x at ~480 MB/s per core. New `scripts/evio_hit_compression.py` ([scripts](reference/scripts.md)). Linked from [run 1](results/2026-11-05-194730UTC-lb677-run1-evio.md#hit-words-vs-all-words).
* **Creation**: `scripts/e2sar_nicmon.sh` ([scripts](reference/scripts.md)): samples the NIC, IP, UDP and TCP counters (by name) and softnet drops once a second on a receiver node, with `start`, `stop` and `report`. `e2sar_e2e_bench.sh` and `e2sar_site2ebpf_recv.sh` run it around the receiver; [streaming-workflow](concepts/streaming-workflow.md#the-workflow), [live-monitoring](howto/live-monitoring.md) and [lb-test](howto/lb-test.md) start it with every run.

A second Ctrl-C stops at once; `--drain-quiet 0` keeps the old order.
